# Diplomski-projekt

Prilagodljivo spletno mesto za Turistično kmetijo Smodiš, izdelano v okviru diplomske naloge z naslovom Oblikovanje prilagodljivega spletnega mesta za mala podjetja z uporabo HTML, CSS in JavaScript.

## Struktura projekta

- `index.html` – domača stran
- `o-kmetiji.html` – predstavitev kmetije
- `ponudba.html` – predstavitev ponudbe
- `cenik.html` – cenik storitev
- `galerija.html` – galerija fotografij
- `kontakt.html` – kontaktni podatki in obrazec
- `zasebnost.html` – politika zasebnosti in informacije o projektu
- `css/` – slogovne datoteke
- `js/` – datoteke JavaScript
- `img/` – slike in drugi grafični elementi
- `img/` – fotografije v formatu WebP

## Uporabljene tehnologije

- HTML5
- CSS
- JavaScript
- EmailJS – pošiljanje e-pošte
- Font Awesome – ikone
- Google Fonts – pisava
- Google Maps – zemljevid

## Glavne funkcionalnosti

- Prilagodljiva postavitev in mobilna navigacija
- Glava strani, ki ostane vidna med pomikanjem
- Gumb za vrnitev na vrh in gladko pomikanje
- Vrtiljaki fotografij in možnost premora samodejnega drsnika
- Filtriranje galerije in povečan prikaz fotografij
- Upravljanje menija, vrtiljakov in povečanega prikaza s tipkovnico
- Odloženo nalaganje slik z uporabo Intersection Observerja
- Prilagodljive slike z uporabo atributa `srcset`
- Fotografije v formatu WebP
- Validacija in pošiljanje kontaktnega obrazca s preverjanjem privolitve
- Obvestilo ob napaki pošiljanja s telefonsko povezavo
- Vdelan zemljevid Google Maps

## Ogled in zagon projekta

Spletno mesto je neposredno dostopno prek GitHub Pages:

[Odpri spletno mesto](https://seboporedos.github.io/Diplomski-projekt/)

Projekt ne zahteva namestitve dodatnih paketov. Za lokalni ogled lahko repozitorij prenesete ali klonirate in nato v spletnem brskalniku odprete datoteko index.html.

Za nalaganje zunanjih storitev in pošiljanje sporočil je potrebna internetna povezava. Delovanje obrazca je odvisno tudi od nastavitev storitve EmailJS.

## Namen kontaktnega obrazca

Obrazec je namenjen preizkusu delovanja v okviru diplomskega projekta. Sporočila prejema avtor projekta, ne lastnik kmetije. Obrazec ni namenjen dejanskim rezervacijam.
