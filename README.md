# Diplomski-projekt

Prilagodljivo spletno mesto za Turistično kmetijo Smodiš, izdelano v okviru diplomske naloge z naslovom Oblikovanje prilagodljivega spletnega mesta za mala podjetja z uporabo HTML, CSS in JavaScript.

## Struktura projekta

- `index.html` - Domov – domača stran
- `ponudba.html` - Ponudba – predstavitev ponudbe
- `cenik.html` - Cenik – cenik storitev
- `galerija.html` - Galerija – galerija fotografij
- `kontakt.html` - Kontakt – kontaktni podatki in obrazec
- `css/` – slogovne datoteke
- `js/` – JavaScript datoteke
- `img/` – slike in drugi grafični elementi

## Uporabljene tehnologije

- HTML5
- CSS
- JavaScript
- EmailJS (zunanja storitev za pošiljajne e-pošte)
- Font Awesome

## Glavne funkcionalnosti

- Responsive design
- Mobilna navigacija (Hamburger menu)
- Sticky header
- Scroll-to-top button
- Smooth scrolling
- Image carousel
- Filtriranje galerije
- Lightbox prikaz slik
- Lazy loading slik z uporabo Intersection Observerja
- Responsive images z uporabo `srcset`
- Validacija in pošiljanje kontaktnega obrazca
- Interactive Google Maps
